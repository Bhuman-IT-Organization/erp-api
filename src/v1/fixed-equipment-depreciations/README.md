# fixed-equipment-depreciations

## Purpose

Manages the Fixed Equipment depreciation settings: the list of depreciation terms (a name and a number of months) that assets and asset models refer to. It replaces Perfex's Fixed Equipment → Settings → Depreciations tab (`admin/fixed_equipment/settings?tab=depreciations`), with the screen at `/setup/fixed-equipment-depreciations` in `erp-web` and the API at `api/v1/fixed-equipment-depreciations`.

## Owned tables

- `tblfe_depreciations`: claimed in the ownership register and written through Prisma. Node writes `name`, `term` and, on create, `creator_id` (the signed-in member) and `date_creator`, which Prisma sends as the api's own time in UTC (**Difference**: Perfex's insert uses the database clock); `id` is set by the database. An edit changes `name` and `term` only.

## Facade surface

- `describe()`: the module and its contract version, `{ module: 'fixed-equipment-depreciations', version: 1 }`
- `findById(id)`: one depreciation, or `null` when there is none
- `listAll()`: every depreciation, the name ascending, then the id; refused above 1000 rows, never truncated

## Endpoints

Under `api/v1/fixed-equipment-depreciations` (`FIXED_EQUIPMENT_DEPRECIATIONS_ROUTES` in `fixed-equipment-depreciations.routes.ts`). Every handler carries `JwtAuthGuard` and `PermissionGuard` and declares its codes from `FIXED_EQUIPMENT_SETTINGS_CODES.depreciation` (`@erp/contracts`): the five groups Perfex's tab serves, the depreciation settings group (mapped from Perfex's `fixed_equipment_setting_depreciation`) and the assets, licenses, accessories and consumables groups. No bearer is 401 `ERP-AUTH-0004`, a missing code 403 `ERP-AUTH-0005`. The reads are `@PermissionsRead(codes.read)`: any group's full view reads every row; otherwise any group's view own reads only the rows the member created. Each write is `@PermissionsAny` over that action's code in the five groups. Every failure is an RFC 9457 problem with an `ERP-*` code.

| Method   | Path     | Code                         | Success                                                                     | Errors beyond the standard ones                                                                                                                                                                                                                                                                    |
| -------- | -------- | ---------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`    | ``       | any group's view or view own | 200 `{ data, meta }`                                                        | 400 `ERP-VALIDATION-0001`                                                                                                                                                                                                                                                                          |
| `GET`    | `export` | any group's view or view own | 200 the file (`csv`, `xlsx`, `pdf`) or `print` rows of `id`, `name`, `term` | 400 `ERP-VALIDATION-0001`                                                                                                                                                                                                                                                                          |
| `GET`    | `:id`    | any group's view or view own | 200 the depreciation                                                        | 404 `ERP-CORE-0004`, 400 `ERP-VALIDATION-0001`                                                                                                                                                                                                                                                     |
| `POST`   | ``       | any group's create           | 201 the depreciation                                                        | 400 `ERP-VALIDATION-0001`                                                                                                                                                                                                                                                                          |
| `PATCH`  | `:id`    | any group's edit             | 200 the depreciation                                                        | 404 `ERP-CORE-0004`, 400 `ERP-VALIDATION-0001`                                                                                                                                                                                                                                                     |
| `DELETE` | `:id`    | any group's delete           | 204, no body                                                                | 404 `ERP-CORE-0004`, 400 `ERP-VALIDATION-0001`, 409 `ERP-FIXEDEQUIPMENTDEPRECIATIONS-0001` (an asset model or an asset uses it; the detail names the non-zero groups, for example "used by 2 asset models and 1 asset"), 409 `ERP-FIXEDEQUIPMENTDEPRECIATIONS-0002` (its use could not be counted) |

Under a view own, another member's row is the same 404 as a missing one.

## Events published

| Event                                          | When                      | Payload                                              |
| ---------------------------------------------- | ------------------------- | ---------------------------------------------------- |
| `fixed-equipment-depreciations.record.created` | after `POST` stores it    | `{ id, at }`, `FixedEquipmentDepreciationsCreatedV1` |
| `fixed-equipment-depreciations.record.updated` | after `PATCH` saves it    | `{ id, at }`, `FixedEquipmentDepreciationsUpdatedV1` |
| `fixed-equipment-depreciations.record.deleted` | after `DELETE` removes it | `{ id, at }`, `FixedEquipmentDepreciationsDeletedV1` |

Declared in `events/published.ts` (`FIXED_EQUIPMENT_DEPRECIATIONS_PUBLISHED_EVENTS`), published through `DOMAIN_EVENT_PUBLISHER` from `service/fixed-equipment-depreciations.transport.ts`. A payload carries the id and the server time, never the name. After each publish the service writes one `LoggerService.log` line, `depreciation created|updated|deleted` with `{ id }`.

## Events subscribed

None. Listed in `events/subscribed.ts` (`FIXED_EQUIPMENT_DEPRECIATIONS_SUBSCRIBED_EVENTS`, empty).

## Jobs

None.

## Resilience

- **Breaker:** none: no outbound HTTP, no vendor call.
- **Retry policy:** none on writes: an unkeyed `POST` retried could create two rows, and the events are in-process.
- **Pool budget:** shares `POOL.db.api` (`connection_limit` in `DATABASE_URL`); one list page costs three queries: the page itself and two counts (the total, and the rows before the page for the range start).

```bash
corepack yarn test src/v1/fixed-equipment-depreciations
corepack yarn test:int src/v1/fixed-equipment-depreciations
```

The int spec needs the local database running and skips without `DATABASE_URL`.
